# Apollo Estética Automotiva

Site estático feito em HTML, CSS e JavaScript. Não precisa instalar dependências nem gerar uma pasta de build.

A logo original está em `images/apollo-logo.png` e é carregada pelo cabeçalho sem alterações.

## Publicar na Vercel

### Envio direto

1. Acesse [vercel.com/drop](https://vercel.com/drop).
2. Arraste a pasta do projeto para a página e escolha **Deploy**.

O arquivo `index.html` está na raiz, então ele será a página inicial do site.

### Com um repositório Git

1. Importe o repositório do projeto na Vercel.
2. Use **Other** como framework, sem comando de build, e mantenha a raiz do projeto como diretório de saída (`.`).
3. Selecione **Deploy**.

As imagens e fontes visuais do site são carregadas de serviços externos; mantenha acesso à internet para que apareçam corretamente.
